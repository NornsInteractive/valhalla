# Valhalla 1.0.9+10 新版本发布

用户纠正发布策略：不再同版本覆盖，从现在开始每批新包都必须新增版本号。
本次新增1.0.9+10、GitHub v1.0.9与原分发项目的新版本（目录code2010）；保留全部已发布版本，尤其不再改1.0.8。
Android真实code分别arm64=2010、armv7=1010、x86_64=4010，Linux基础build10。

本轮仅版本／规则文档更新，不再修改产品UI；上一批产品功能保留紧凑快捷键与常驻一体倒T方向组。
本地正式签名Android三架构APK／AAB和Linux x64，沿用固定证书与com.norns.valhalla；不启动Actions，不做ADB安装。
构建／测试／产物和公开下载验证交OpenCode已核验免费模型，主／辅助模型都显式固定免费，不继承以前直接执行例外。
每个新分发包及版本都开启use_proxy，公开下载需按平台／架构／package_id核对整包SHA256与Range206。
