# 本地会话与终端搜索

- 智能会话新增本地全文搜索，默认当前会话，可切换当前服务器，沿用 Agent/共享会话隔离。支持正文、代码和已保存的完整工具输出，分批加载结果；远端历史继续手动导入。
- 命中打开独立只读上下文，显示角色、来源和匹配片段，长内容按需展开、完整复制，工具输出定位并分页；不替换活动会话或草稿。
- SSH 终端新增本地缓冲搜索、上一处/下一处和返回最新输出。各终端独立保存搜索词，支持 Ctrl+Shift+F／macOS Cmd+F，Ctrl+F 继续发送远端。
- 修复共享 xterm 满缓冲重排及清理前缀后的索引/脱离状态，避免错误定位引起反复搜索；关闭、切换终端和后台恢复丢弃迟到结果，保持输入法与阅读位置。
- 收紧会话抽屉头部按钮，保留原有底部快捷栏布局和自定义颜色。

验证：42 文件 514 项常规重点回归通过，零失败/跳过；语言生成、格式、全项目静态分析零问题和差异检查通过。共享缓冲与终端 UI 的 21 项独立回归通过；集合重叠不相加。正式构建和渠道验证结果以发布回执为准。

搜索只读取 App 已保存的本地历史和终端缓冲，最多显示 1000 个终端匹配并明确提示；不自动拉取远端历史。未进行真实 Agent/生产 SSH/tmux 或 ADB 验收，未构建 Windows/Apple，也不启动 Actions。第三阶段命令偏好与上下文/快捷操作仍在准备，不计为本版本交付。
