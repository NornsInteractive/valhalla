# SSH 终端与智能会话稳定性改进

- SSH 页签显示连接状态，支持针对单个页签重连；关闭前按终端类型确认，保留至少一个页签。
- ACP 任务与当前查看的会话分离：可在运行时浏览其他会话、切换 Agent、编辑草稿，同一服务器限制一个执行中的任务。
- 增加返回运行中会话入口；重连保存已有内容，后台接收和保存输出。
- 审批卡片显示摘要，完整命令在详情中查看和复制；审批与停止操作校验原服务器和会话目标。
- 删除会话默认仅删除本地记录，可明确选择停止并清理 App 管理的运行缓存；清理失败保留本地会话。
- 已结束或过期的运行实例在确认后换代恢复原远端会话，保留历史，不重发旧指令；Agent 更新前检查运行中的任务。
