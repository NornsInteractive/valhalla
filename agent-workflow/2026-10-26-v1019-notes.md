# Valhalla 1.0.19

- 智能会话重新进入时优先恢复本地记录，显示最后一页消息；连接恢复不会遮住已有消息，继续上滑阅读时保留位置。
- 智能会话中的网址、邮件与远端文件链接可打开；文件链接按所选服务器和执行环境解析，工作目录之外的路径需要确认。
- 智能会话新增工作台：按服务器、执行环境和工作目录分组，支持项目别名与收藏；提供文件、任务和上下文面板。
- 支持有界文本预览与编辑，保存前查看差异并确认；检测到外部改动或目标切换时拒绝覆盖并保留草稿。远端 localhost 网页在确认后通过 SSH 转发打开，Docker 仅使用已有发布端口。
- SSH 历史恢复前刷新未知状态，保留严格的 tmux 身份和脱敏错误详情；失败可查看、复制诊断并重试原记录，不创建替代会话。

## 验证范围

核心、界面和协议使用自动化与隔离测试：422 项 Flutter 测试和 34 项 Python Broker 测试通过，语言生成、格式、全项目静态分析（零问题）与差异检查通过。OpenCode 免费额度用尽后，本轮按授权由 CodeBuddy 免费模型继续验证与执行既有发布脚本。构建与渠道校验结果以发布回执为准，中途失败日志不计为通过。

本次本地构建正式签名 Android 三架构 APK/AAB 与 Linux x64，不启动 GitHub Actions。不进行 ADB 安装或真实 Agent/生产 SSH 对话验收，不构建 Windows/macOS/iOS；Windows 商店独立更新。

文本编辑上限 1 MiB。容器缺少安全编辑工具时仅支持只读预览；非协作外部写入者仍可能在最终校验与原子重命名之间竞争，重要文件应由服务端权限和协作流程共同保护。
