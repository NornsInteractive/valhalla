# Valhalla 1.0.12+13 发布记录

用户要求修复终端快捷键栏输入法焦点与重绘问题，并打包推送到 GitHub Release 新版本。沿用本地正式签名 Android 三架构 APK／AAB、Linux x64，新增 v1.0.12，不覆盖历史版本，不启动 Actions，不执行 ADB 安装。

发布前最新为 1.0.11+12；本次基础 build=13，Android arm64／armv7／x86_64 真实 code 为 2013／1013／4013。应用标识与固定正式证书不变。

本轮修复内容：
1. **编辑抽屉文本框输入法呼出**：移除外层遮蔽焦点的 `ExcludeFocus`，为编辑抽屉配置独立 `FocusScope`，确保按键标签、自定义按键名称与文本宏输入框均能正常获取输入焦点并调起软键盘输入。
2. **软键盘切换按钮单次点击唤起**：实现 `WidgetsBindingObserver.didChangeMetrics` 监听视图底层键盘 inset 高度变更，同步跟踪移动端软键盘真实弹出/关闭状态，修复从软键盘自带收起按钮手动关闭后需要点击两次才能重新呼出的问题。
3. **悬浮抽屉架构（Overlay 模式）杜绝终端重绘**：将编辑抽屉与快捷抽屉调整为悬浮在终端上方的叠加层，底部有效布局高度（`effectiveBottomSpace`）仅随基准快捷栏高度变化；抽屉展开与收起不再挤压底层终端视口，彻底消除终端 PTY resize、缓冲区跳动与 SSH SIGWINCH 触发的整屏刷新重绘。

构建证据目录：`build/local-packages/v1.0.12-release/`。本地构建、正式签名、审计归档、GitHub 附件全部通过，已公开发布。
