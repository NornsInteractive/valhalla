# Valhalla 1.0.24

新增服务器工作区：同一 SSH 用户的多台设备可共享 Agent 配置、智能会话、终端历史索引、文件书签、应用中心与 NAS 元数据。新设备仍需自行配置 SSH 并确认主机密钥，在设置中明确启用工作区后同步；不会自动上传所有本机设置。

- 多设备共同查看 ACP 会话，单设备持有操作控制权；接管后旧设备的写操作被拒绝，正在运行的 Agent 不因接管而停止。新设备按已有运行索引发现会话，不创建重复运行。
- 配置按版本合并，保留断线修改与冲突；草稿按设备保存，只在手动恢复时替换当前草稿，并备份被替换内容。
- 消息、附件和 NAS 索引按页或按需获取，旧索引分批迁移并保存进度。同步刷新保留当前选择和本机缓存。
- SSH 密码、私钥、主机信任和 NAS 认证信息保留在设备。NAS 源目标改变后不会把旧密码发往新地址。
- 手机、平板与桌面偏好分别保存，应用级偏好使用明确指定的服务器来源。

服务器要求 Python 3.9+，工作区通过现有 SSH 连接使用标准库 SQLite；无需额外公网端口或 sudo。启用与维护说明见 `docs/server-workspace.md`。

本版提供本地构建的正式签名 Android 三架构 APK/AAB 与 Linux x64。Windows 和 Apple 平台本轮不构建。检查结果、安装验收与发布回执在同批实施记录中登记；未使用现有生产 Agent 对话作测试，两台真实设备同时操作和真实 Agent 长任务恢复仍需后续验收。

---

Server workspaces let your own devices share Agent configuration, chat history, terminal history references, file preferences, application metadata and NAS indexes through the same SSH account. Enable synchronization explicitly in Settings after configuring SSH on each device.

ACP sessions support multiple observers and one writer, with fenced takeover that leaves the running Agent intact. Versioned updates preserve offline edits and conflicts; device drafts require explicit restoration. Messages, attachments and NAS indexes load in bounded pages. SSH credentials, host trust and NAS authentication remain local.

Requires Python 3.9+ on the server, using SQLite over SSH without a public service or sudo. This release ships signed Android packages and Linux x64; Windows and Apple builds are outside this release. Production Agent conversations and simultaneous physical-device takeover have not been used as acceptance tests.
