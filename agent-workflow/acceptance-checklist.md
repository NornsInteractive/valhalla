# Agent 交付验收清单

## 范围

- [ ] 修改文件全部位于 handoff 白名单。
- [ ] 没有越界修改业务层、基础设施或无关生成文件。
- [ ] 共享文件的改动已明确说明。

## UI

- [ ] 默认、加载、空、错误和成功状态完整。
- [ ] 桌面、平板和移动端没有溢出或不可用布局。
- [ ] 浅色、深色和项目主题色表现一致。
- [ ] 所有界面文字来自 ARB 或既有本地化资源。
- [ ] 交互可通过键盘或辅助技术完成。

## 工程验证

- [ ] `dart format` 或项目约定的格式化命令通过。
- [ ] `flutter analyze` 通过。
- [ ] 相关测试通过。
- [ ] 需要真实设备、服务器或网络的项目已单独标记验证状态。
- [ ] handoff 或 implementation-status 已记录实际结果和剩余风险。
