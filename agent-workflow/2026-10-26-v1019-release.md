## 未覆盖与限制

本轮按约定不安装 ADB，不操作真实 Agent 对话或生产 SSH/tmux；真实服务器恢复失败的具体根因仍需新包诊断，不能把隔离回归宣称为实服验收。未构建 Windows/macOS/iOS，未触发 Actions。

文本编辑上限 1 MiB，缺少容器 Python3 时只读，不安装工具或提权。最终校验与原子重命名间仍可能与非协作外部写入者竞争；完全消除此窗口需要服务器协作锁。远端网页转发仅支持确认后的 HTTP loopback，Docker 仅使用既有发布端口。
