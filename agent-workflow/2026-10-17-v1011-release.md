# Valhalla 1.0.11+12 发布记录

用户要求将本轮改版的 SSH 终端原型网格快捷栏打包发布到 GitHub Release。沿用本地正式签名 Android 三架构 APK／AAB、Linux x64，新增 v1.0.11，不覆盖历史版本，不启动 Actions，不执行 ADB 安装。

发布前最新为 1.0.10+11；本次基础 build=12，Android arm64／armv7／x86_64 真实 code 为 2012／1012／4012。应用标识与固定正式证书不变。

变更为 8 列网格快捷键栏原型体系：
- 8 列标准单元格网格布局，支持多页滑动切换与分页指示点。
- 支持按键长按拖拽重排、空位放置、1x1 键位互换。
- 内置 3x2 倒 T 方向键组，支持按住连发与拆分/合并逻辑。
- 三栏编辑抽屉（添加／按键／设置），包含 8 个预设分类、常用符号、自定义组合键与文本宏。
- 本地存储与持久化同步，支持行数调节与页面增删管理。
- 保留修饰键跟踪、Gboard 软键盘联动、长按连发与无损兼容链路。

构建证据目录：`build/local-packages/v1.0.11-release/`。
