# ACP 后台持续运行与每日更新提醒

- ACP 对话支持用户确认后部署服务器后台代理。切换应用、锁屏或关闭应用后，已受理任务继续运行；重新打开后按进度补齐输出并继续接收。适用于宿主机和 Docker Agent。
- 审批跨断线保留，关闭应用不会自动拒绝；停止按钮仍明确取消任务。完成输出在服务器保留七天。
- 修复恢复时提前结束、重复触发登录、成功回答被标为失败，以及恢复提示无法关闭的问题。
- 每天首次进入前台按本地日期检查更新，有新版本时弹窗；同日不重复，输入法或其他弹窗打开时延后。

服务器需 Python 3.9 或更高版本。主机重启、容器/Agent 被管理员停止或磁盘故障不属于持续执行保证；旧版已退出的任务不能凭空恢复。

验证：OpenCode 完成语言生成、全项目静态分析（零问题）、180 项 Flutter 回归和 12 项代理回归。
Android 模拟器通过真实进程强制关闭/重新启动测试：关闭期间服务端输出继续，重开后恢复 30 条有序记录，请求数为 1；已恢复正常 App 入口安装。
设备测试使用隔离模拟 Agent，未验证真实 Codex/AgY 账号、Docker 实际 Agent、物理手机或 Windows/Apple 原生环境。
本次本地发布 Android 三架构 APK/AAB 与 Linux x64，不启动云端构建。
