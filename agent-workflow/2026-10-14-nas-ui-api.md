## Reuse existing capabilities

- `NasIndexGroupCount` already has `representative: NasMediaItem?`, `key`,
  `count`, `totalDurationMillis` and date range. No new cover DTO or database.
- Folder photo albums: `nasProvider.notifier.groups(NasIndexGroup.byFolder,
  kind: NasMediaKind.image)`; album/artist groups default audio. Page with
  `after: last.key`; at most200 groups. SQL already batches representative items.
- Cover: `NasThumbnailImage(item: group.representative!)`, null -> honest themed
  placeholder. It already owns/cancels thumbnail requests and uses sourcecache.
- Album scope is `setScope(albumKey: group.key)` (not displayname); artist uses
  `setScope(artist: group.key)`. Guard source/navigationepoch after await.
- Home `nasHomeProvider` provides real continue video/audio and recent shelves,
  favorites and playbackByPath. No extra full-list scans or fake recommendations.
- `NasNotifier.openInApp(item)` captures source/query/sort/pagecursor; group
  play-all must first enter proper scope, awaitload, guardtarget, play firstitem.
- `nasPlaybackProvider` / `NasPlayerSnapshot`: current item, queue and playback.
  Player cover uses existing `NasThumbnailImage(snapshot.current)`.
  Existing controls: playOrPause,seek,next,previous,jumpTo,shuffle,repeat,rate,
  audio/subtitle tracks,quality,retry. Do not duplicate playback service.
- Photo density is local view state per-source (default4, choose3/4/5), not a
  new database setting. Existing captureVisibleAnchor/itemToRowIndex/offsetOfRow
  + two-phase correction must preserve item+pixel on density changes. Existing
  photo max600 and normal page200 remain; no unlimited widget lists.

## New minimal music queue API

`NasNotifier.addToQueue(NasMediaItem item) -> Future<void>` appends an item to
the CURRENT LOADED audio queue without restarting playback or progress.
Only same-source audio, nonempty current queue; currently queued paths are
idempotent, max600. Existing pagination remains captured, skips one duplicate
when later naturally reaching a manually appended path. This is not a saved
playlist edit and not a promise of append-after-entire-remote-library.

Disable add action for empty/non-audio/cross-source queue; errors still handled
for races. Localize `NAS_QUEUE_BUSY`, `NAS_QUEUE_CHANGED`, `NAS_QUEUE_AUDIO_ONLY`,
`NAS_QUEUE_SOURCE_MISMATCH`, `NAS_QUEUE_FULL`; reuse existing handling for
NAS_PLAYER_EMPTY/CLOSED and NAS_SOURCE_NOT_FOUND/CHANGED. No raw code toast.
