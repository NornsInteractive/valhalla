# Valhalla 1.0.40+41

## SSH 终端上下滑动手势重构（对齐鼠标滚轮）
- **触控与触控板纵向滑动交互优化**：重构终端手势调度引擎，使触控屏滑动与触控板双指滑动体验完全对齐鼠标滚轮。
- **Alternate Buffer 模式精准映射**：在 `tmux`、`vim`、`less`、`htop` 等全屏交互工具中，将上下滑动位移转换为鼠标滚轮与方向键事件，并增加平滑动力惯性减速（Fling），告别无响应或顿挫感。
- **普通缓冲区历史回滚与触底吸附**：在标准输出缓冲区下无缝联动 `ScrollController` 浏览历史日志，滑动松手自然恢复触底吸附。
- **划选与快捷键零回归**：严格限定触控手势识别设备类型，桌面端鼠标左键拖拽框选文本、双击选词及底部快捷输入栏交互不受任何影响。

## 顶部提示栏彻底清理与右上角轻量加载动画
- **移除全部遮挡性浮动横幅**：彻底移除了顶部悬浮的「重新连接提示条」、「会话恢复失败横幅」以及终端内部错误提示条，恢复清爽整洁的界面视觉。
- **右上角服务器加载指示器**：在桌面端顶部状态栏及移动端标题栏的服务器名称旁，接入动态转动的 `CircularProgressIndicator` 状态指示器。在连接中、断线重连中或会话恢复中实时展示，就绪后自动隐去。
