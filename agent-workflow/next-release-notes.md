# Valhalla 1.0.36+37

## 智能会话文件支持、交互与稳定性优化
- **全类型文件支持**：智能会话底部“添加本地文件”与“引入远端文件”全面放开扩展名限制，支持添加任意类型文件；文本文件以 TextResourceContents 发送，非文本二进制文件以 BlobResourceContents Base64 编码发送并支持解码存储。
- **异常事件静默处理**：移除频繁弹出的“已记录异常事件”提示框，相关诊断数据仅在底层日志静默留存，提升界面纯净度。
- **斜杠命令与运行设置自动就绪**：会话建立与切换后自动预加载命令与运行能力，无需先发一次对话即可直接显示模型、思考程度及斜杠命令。
- **精简会话操作**：暂时隐藏智能会话顶部“共享agent会话”按钮及侧边栏开关。
- **工作目录稳定切换**：保持工作目录在顶部标题栏的原位置，修复点击报错问题（使用原生 SFTP host 浏览源避免脆弱的远程 bash 探测），并支持在已有会话及草稿态中随时点击切换与保存工作目录。
