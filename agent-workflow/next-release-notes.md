# Valhalla 1.0.39+40

## 远程文件传输极速优化与带宽跑满
- **核心对称加解密算法首选项调优**：置顶纯 Dart 性能极致的 `ChaCha20-Poly1305` 与 `AES-CTR`，单流加解密速度从 0.8 MB/s 暴增至 75 MB/s（近 100 倍提升），彻底消灭软解 AES-GCM 导致的 CPU 满载瓶颈。
- **TCP 与底层流控深度调优**：开启 `tcpNoDelay` 消除 40~200ms Nagle 延迟；扩容 SSH 初始通道流控窗口至 16MB，消除高时延公网与跨地域网络下的 BDP 限制。
- **SFTP 读写在途请求深度扩容**：后台传输 Worker 管道在途深度提升至 128（4~8MB 在途流水线），填满网络管道。
- **多流多任务并发队列与用户配置**：引入可配置并发调度引擎（默认 3 并发），在设置页提供「传输并发数」设置（1/2/3/4/6 挡位自适应切换），批量传输跑满多核 CPU 与物理网络带宽。
- **Windows 全平台支持**：提供 Windows x64 便携 ZIP、Inno Setup 安装包及 MSIX 商店分发包。
