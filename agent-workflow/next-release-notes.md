# Valhalla 1.0.38+39

## 智能会话工作目录分状态展示与不可变保护
- **未确认工作目录状态（草稿阶段）**：显示在输入框上方药丸胶囊 `[📁 目录名 ▾]`，点击可自由唤起目录浏览器修改，小屏不再折行挤压，顶部标题栏保持清爽。
- **会话进行中状态（首条消息已发送）**：输入框上方工具栏不再显示胶囊；工作目录恢复显示在顶部 Agent 名称下方（`📁 /path/to/project`），只读展示当前会话绑定的工作目录，避免修改导致底层 ACP 协议与会话环境脱节。
- **超窄屏防溢出适配**：顶部 Agent 与工作目录展示增加自适应缩放，防止在 320px 超窄屏及超大字体缩放下发生溢出。
