# SSH终端历史与多来源 tmux 管理

- 历史记录区分可连接、已结束和来源未配置；远端已终止的会话不可恢复，不会意外创建同名终端。
- 支持发现服务器默认 tmux、App 专用 tmux，以及手动配置的具名或绝对路径 socket；外部会话可连接、重命名及设为默认启动。
- 分离“隐藏本机记录”和“终止远端会话”；终止前明确确认服务器、来源和客户端影响，保留已显示的输出。
- 支持查看和取消隐藏；抽屉前台打开时每15秒刷新，局部来源错误不清空其他会话。
- 保留旧历史原始数据；使用远端稳定身份防止误恢复或误杀同名重建会话，服务器切换时取消过期操作。
- 优化小屏、放大字体与RTL历史抽屉，采用懒加载；弹窗关闭不唤起终端输入法。

发布前静态分析零问题，36文件598项终端/存储/组件回归全部通过，包含多语言一致性与隔离真实 tmux 闭环；发布脚本另保留正式构建与校验证据。
范围：原证书正式签名 Android 三架构 APK/AAB、Linux x64；不启动 Actions，无 Windows/Apple 包，未进行 ADB 或生产服务器交互验收。
