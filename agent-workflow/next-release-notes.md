# Valhalla 1.0.42+43

## SSH 终端长按文本选区调节手柄与微调支持
- **选区调节手柄（Selection Handles）**：在终端界面长按选中文本后，松开手指时在选区起始与结束位置呈现 Material 规范的水滴调节手柄（起始左手柄与结束右手柄），触控热区扩展至 44×44dp。
- **自由微调选区范围**：用户可通过拖拽左右手柄向前、向后自由调整字符选取边界；内置防交叉边界约束（最小保留 1 字符）与视口边缘自适应滚动能力。
- **空白区域点击一键取消**：点击手柄外部任意区域即时清除选区，保持操作轻快高效；选区变化实时同步至右上角复制胶囊栏。
- **非词字符长按兜底与触感反馈**：长按非词、符号或空白处自动回退到单字符选定，配合轻微触感振动反馈，彻底解决长按松开后无法选择与调整范围的问题。
