# Valhalla 1.0.30+31

## 智能会话运行设置与项目目录结构优化
- 输入框上方设置栏全面展示所有运行设置项：模型、思考程度、智能体模式、本地权限策略以及运行时附加设置（extraSettings）。
- 附加开关特性支持关闭隐匿：开关类设置在关闭状态下不予展示，开启时显示对应胶囊徽标；下拉类型设置展示对应选中项标签。
- 项目工作目录迁移至顶部标题栏（Session Header）：彻底移出底部设置栏以释放横向空间；在顶部标题栏中与智能体身份组合为紧凑双行显示，草稿态支持浏览/切换与快速重置，自适应窄屏与大字号防溢出。
- 底部输入框工具按钮极致紧凑化：附件菜单与命令/技能按钮尺寸收敛为 26x30，间距缩减为 0px，为右侧输入框释放最大打字区域。

## 验证与稳定性
- 全量静态分析（flutter analyze --no-pub）零告警。
- 新增附加设置开关可见性、模式展示与工作目录迁移的组件测试全部通过。
- 沿用 Norns Interactive 正式证书签名 Android 三架构 APK/AAB 与 Linux x64 包。
