## 验收边界

实际设备测试采用隔离模拟 Agent，未向真实 Codex/AgY 生产会话发送消息，
也未完成 Docker 实际 Agent、物理手机或 Windows/Apple 原生验收。
后台持续运行需服务器 Python 3.9+；输出恢复保留期为七天，服务器/容器/Agent 被终止或存储故障不属于持续运行保证。
每个聊天/Agent 的进程成本及空闲池限制见[实施契约](../docs/handoffs/2026-10-23-acp-durable-runtime.md)。
