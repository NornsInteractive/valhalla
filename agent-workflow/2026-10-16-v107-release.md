# Valhalla 1.0.7+8 发布

范围：本地正式签名 Android 三架构 APK、AAB、Linux x64；GitHub Release 与原分发项目同步。不启动 GitHub Actions。

本次包含 SFTP 后台传输与刷新性能优化、远程文件工具栏配置和紧凑视图、终端普通／tmux 创建策略与历史管理、Agent 更新检测及确认流程、重连浮层提示和相关回归。

## 安装兼容性

Android 包名现为 `com.norns.valhalla`，正式签名保持原证书。历史 1.0.6 使用 `com.antigravity.valhalla.valhalla`，不能直接覆盖迁移私有数据；新旧应用可以并存。请从旧版导出配置后在新版导入，重新配置登录凭据。配置备份不包含密码、私钥、会话正文、终端历史、下载文件或 NAS 索引。不要卸载旧版来尝试迁移。

## 验证边界

前一轮同一产品源码已经通过全量 Flutter 测试（3856 通过、30 个外部环境依赖跳过）、静态分析和 Android x86_64 ADB 安装验收；详细证据见 `2026-10-16-agent-update-apk-adb.md`。本轮版本号变更后重新检查、重新构建，不重命名旧包冒充新包。

宿主机旧 Codex ACP 0.16.0 内嵌运行时与新版 CLI 不一致的问题仍需单独验证／升级，不能将本次发布理解为该服务器真实对话已验收。没有执行真实服务器 Agent 升级。

发布完成后补记源码提交、产物哈希、平台记录及公开下载验证结果。
