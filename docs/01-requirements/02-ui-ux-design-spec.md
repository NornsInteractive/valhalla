# Valhalla - UI/UX 与响应式交互设计规范

## 2026-09-19 设置与仪表盘交互增量

- 设置页的单选项目使用“标题 + 当前值 + 进入符号”摘要行，点击打开适配手机与桌面的弹窗；布尔开关、多选底栏不被强行改为单选。主题色弹窗提供三个模式切换、预设色、HSV 可视化调节、`#RRGGBB` 输入、预览及确认/取消，系统模式解释为自动使用浅色/深色设置。
- 服务器名称旁使用紧凑的操作入口承载重启、关机、断开连接，窄屏不得截断服务器身份信息；危险操作需要二次确认。系统持续运行移入信息卡，原卡位置展示默认路由网卡上下行，点击展示所有网卡明细；没有可计算速率时不画百分比进度。
- 快捷入口设置允许勾选、拖动排序和全部隐藏；导航目标以稳定页面 ID 映射，移动端 320dp 宽度下无溢出。

## 2026-09-19 展示增量

沿用现有 Material 3、主题、响应式侧栏 / 抽屉与中英文资源，不重设计导航风格。CLI 是独立入口，不替换 ACP；原生列表、草稿、逐次审批、真实终端、明确远端删除确认按能力显隐。重启确认绑定捕获目标与活动连接 / 传输数量，已受理与完成验证必须区分。Docker 匹配操作按钮加载，同容器冲突禁用，其他容器可操作。由指定 agy Valhalla 会话实现，业务方不修改 UI。契约与性能待验收项见 [本轮交接](../handoffs/2026-09-19-cli-reboot-performance.md)。

### 2026-09-19 细节优化与硬件展示交互规范

1. **ServerFormDialog 自适应与校验优化**：
   * **视口自适应**：移动端（窄屏）采用 `Dialog.fullscreen`，包含固定的顶部标题栏与底部保存按钮栏，中部滚动视图自动避让系统输入法键盘 (`viewInsets.bottom`)；桌面与宽屏采用居中浮窗，限制最大宽度 560dp 与最大高度 720dp。
   * **长私钥可查看**：私钥输入框支持等宽代码字体 (`JetBrains Mono`)，提供可折叠展开切换，便于核对 SSH 密钥指纹与内容完整性。
   * **联通性测试与表单校验**：实时测试卡片内嵌于表单可滚动区域中，明确展示测试中、成功或失败原因；表单支持名称非空、主机/IP有效性、端口号 (1-65535) 与用户名校验，保存失败展示脱敏的通用本地化错误 (`serverSaveFailedGeneric`) 与 SnackBar 双重提示，禁止向用户界面直接暴露包含文件路径或凭据的原始底层异常。

2. **DockerView 容器 Shell 切换与终端自适应**：
   * **每容器 Shell 选择**：每张容器卡片右侧提供 Bash / Sh 下拉切换控件，初始默认优先读取本地存储偏好 (`localStorageServiceProvider.getContainerShell`)，若未设置默认选择 `DockerTerminalShell.bash`。
   * **回退提示与资源释放**：调用 `DockerCliService.openTerminal` 传递首选 Shell；当后端探测 Bash 不可用并自动降级为 Sh 时，弹出轻量 SnackBar (`dockerBashFallbackNotice`) 提示用户；终端关闭时自动调用 `bridge.dispose()` 释放通道，非运行中容器禁用进入按钮。
   * **窄屏响应式流式布局**：卡片操作按钮与 Shell 选择器通过 `Wrap` 流式排布与紧凑按钮主题，确保在 320dp 极致窄屏下无 `RenderFlex` 溢出。

3. **SFTP 点目录规范清洗**：
   * **目录层级规范**：根目录 (`/`) 严格隐藏 `.` 与 `..`；子目录隐藏代表当前目录的 `.`，但保留代表上一级的 `..` 便于快捷返回上一级。
   * **列表渲染安全**：清理残留展示逻辑，在 `_buildListItem` 与点击处理中对非法点目录进行防御性过滤与拦截。

4. **CLI Chat 草稿远端工作目录选择器**：
   * **草稿状态显隐**：仅在空白草稿状态 (`state.activeSession == null && state.structuredSend`) 渲染工作目录配置卡片；开始发送后进入加载禁用态，会话生成后由后端会话记录接管。
   * **独立 SFTP 目录浏览器**：点击浏览弹出远端目录树对话框，使用 `ref.read(sftpOperationsProvider).listFiles(path)` 浏览目录结构，完全隔离 SFTP 主文件视图状态；支持快速返回上一级、目录路径输入跳转、错误重试与重置为默认工作目录。
   * **安全防串扰与状态防护**：对话框在加载中或错误状态下禁用确认选择按钮；向上导航按钮具备本地化提示 (`cliNavigateUp`)；若在弹窗开启期间外部发生服务器切换或断线，关闭时自动拦截，禁止将旧服务器路径写入新服务器草稿。

5. **AI / CLI 会话抽屉导航图标统一**：
   * 移动端顶部应用栏统一将会话抽屉展开按钮图标由传统汉堡菜单替换为侧栏符号 `Icons.view_sidebar_outlined`，并绑定本地化提示文案 `chatSessionsTooltip`。
   * 在 `cli_chat_view.dart` 中显式指定 `AppBar.leading`，防止 Flutter Scaffold 内部自动注入默认系统抽屉菜单图标。

6. **Dashboard 服务器硬件与系统规格视图**：
   * **信息集成**：在服务器连接状态卡片下部，集成硬件规格面板，展示处理器型号与核心数 (`cpuModel` / `cpuCores`)、物理内存总量 (`memoryTotalKiB`)、根磁盘分区容量 (`rootDiskTotalKiB`)、操作系统发行版 (`distribution`) 与内核版本 (`kernel`)。
   * **指标等宽排布**：数值统一使用 `JetBrains Mono` 等宽字体呈现，单位自动格式化为 GB/TB 等易读形式；支持未知字段的本地化占位 (`hardwareUnknown`)。
   * **生命周期与防串扰**：仅在 SSH 连接成功且服务器 ID 匹配时请求展示，断连或切换服务器时自动隐藏并重置，防止跨主机信息残留；下拉刷新 (`RefreshIndicator`) 同时刷新动态监控指标与静态硬件配置。

## 1. 视觉语言与设计系统

### 1.1 设计哲学
* **技术感与专业性 (Technical & Clean)**：作为专业运维与 AI 开发工具，界面减少冗余装饰，以信息密度、排版清晰度和层次分明为最高准则。
* **跨端一致且兼顾平台习惯 (Adaptive Native)**：统一基于 Flutter Material 3 基础组件，但针对桌面（鼠标/键盘/宽屏）和移动（触控/手势/小屏）采用差异化的交互形态。

### 1.2 主题与配色体系
遵循 Material 3 ColorScheme 动态配色系统，并提供高对比度深色模式（AMOLED / True Dark）：

```text
Light Mode          Dark Mode (Default)       AMOLED Dark
┌────────────────┐  ┌────────────────┐        ┌────────────────┐
│ Background     │  │ Surface: #121316│        │ Surface: #000000│
│ Primary: Blue  │  │ Primary: #7C9CFB│        │ Primary: #8EAAFF│
│ Card: #F4F6F9  │  │ Container: #1E2024│      │ Container: #121212│
└────────────────┘  └────────────────┘        └────────────────┘
```

* **状态指示标准色**：
  * Online / Success: `Emerald Green (#10B981)`
  * Offline / Inactive: `Cool Grey (#6B7280)`
  * Running / In Progress: `Sky Blue (#0EA5E9)`
  * Warning / Permission Required: `Amber (#F59E0B)`
  * Danger / Error / Failed: `Crimson Red (#EF4444)`

### 1.3 字体与排版
* **正文字体**：遵循系统字体（Android 使用 Roboto / Noto Sans，Windows 使用 Segoe UI / 微软雅黑，macOS/iOS 使用 SF Pro / PingFang）。
* **等宽字体（Terminal, Code, Logs, JSON, Hash）**：优先使用 `JetBrains Mono`，回退至 `Fira Code` -> `Menlo` -> `Consolas`。

## 2. 跨平台响应式断点体系

采用两级响应式断点（Breakpoints）：

| 设备类型 | 屏幕宽度区间 (`width`) | 主导航形态 | 布局策略 |
| :--- | :--- | :--- | :--- |
| **Compact (手机)** | `< 600 dp` | 底部 `NavigationBar` + Drawer | 单列全屏流式布局，复杂交互采用 Modal BottomSheet |
| **Medium (平板/折叠屏)**| `600 dp ~ 1024 dp` | 左侧折叠 `NavigationRail` | 双栏主从布局（Master-Detail） |
| **Expanded (桌面/大屏)**| `> 1024 dp` | 左侧展开 `NavigationRail` + 侧边栏 | 三栏布局（导航 + 主操作区 + 检查器 Inspector） |

## 4. 关键交互组件规范

### 4.1 Terminal 移动端辅助键工具栏 (Accessory Keyboard Bar)
在移动设备唤起软键盘时，键盘正上方固定吸附一行半透明暗色操作条：

```text
┌───────────────────────────────────────────────────────────┐
│ [ESC]  [TAB]  [CTRL]  [ALT]  [↑]  [↓]  [←]  [→]  [📋粘贴]   │
└───────────────────────────────────────────────────────────┘
```

* **按键交互逻辑**：
  * `CTRL` / `ALT` 为开关按键（Toggle）：按下后高亮高对比背景，随后点击普通字母键即自动触发组合键（如按下 `CTRL` 后再点 `C` 发送 `\x03` SIGINT），随后状态自动复位。
  * `TAB`：发送制表符实现命令行自动补全。
  * 方向键 `↑` `↓`：快速翻阅 bash 命令历史；`←` `→`：移动光标。
  * `粘贴`：直接将系统剪贴板内容写入终端输入流。

### 4.2 AI Agent 会话与 Tool Call 卡片

#### 2026-09-18 交互修订

- 保留既有 Material 3、主题色和响应式布局，不做重新设计；所有展示修改仅由指定 Valhalla AGY 历史会话执行。
- 新建只展示空白草稿，历史不清空；切换 Agent 不产生会话。共享开关默认关闭且随服务器保存，列表由 Provider 过滤，不在页面拼接其他服务器记录。
- 会话删除（包括最后一条）必须出现确认对话框，取消不改数据。登录挑战或发送被拒绝时保留输入。

## 5. 动效与触觉反馈 (Haptics & Micro-interactions)

1. **触觉反馈 (Haptic Feedback)**：
   * 终端按压辅助功能键（Ctrl, Esc）：轻微震动 (`HapticFeedback.lightImpact()`)；

   * 日志与终端流式输出具备智能滚动粘性（Sticky Bottom）：当用户手动向上翻阅查看历史时自动停用滚屏，当滑动回底部时自动恢复自动跟随滚屏。

## 6. 2026-09-20 会话运行设置、抽屉统一与 NAS 媒体库增量规范

### 6.1 会话抽屉与桌面侧栏统一规范 (AiChatView & CliChatView)
- **移动端 Material Drawer 统一**：
  - `AiChatView` 移动端会话列表与 `CliChatView` 对齐，严格使用 Flutter Material 规范的 `Drawer` 组件，支持自然边缘拖拽与蒙层点击遮罩关闭。
  - 会话选择后或点击新建会话后自动关闭抽屉；抽屉内集成会话共享开关与会话删除确认。
- **桌面端会话栏宽度统一**：
  - `AiChatView` 与 `CliChatView` 桌面端会话/Agent侧边栏宽度统一为 `320dp`，保证长会话标题和操作按钮有充足展示空间。
- **窄屏自适应与防溢出**：
  - 顶部应用栏中的 Agent 切换下拉控件使用 `Flexible` 包裹，防止超窄视口（320dp~400dp）下与功能按钮产生横向 `RenderFlex` 溢出。

### 6.2 智能会话与 CLI 运行设置规范 (ChatRunSettings)
- **入口集成与忙碌保护**：
  - `AiChatView` 顶部工具栏与 `CliChatView` 桌面侧栏/移动端顶部栏集成运行设置图标按钮 (`Icons.tune`)。
  - 在生成中 (`isGenerating`) 或发送中 (`isSending`) 期间，设置入口自动禁用，防止并发修改运行时参数造成状态不一致。
- **配置项模型与自适应回退**：
  - **模型与推理等级**：支持按 Agent 运行时能力 (`AgentRuntimeCapabilities`) 动态选择；列表为空时默认展示为“Agent 默认”；非结构化 CLI 会话（如交互式 Claude Code）展示“由交互式 CLI 管理”并禁用选择。
  - **操作权限策略 (3档)**：
    1. `askEveryTime`：每次询问
    2. `autoAllowSafe`：自动允许安全操作
    3. `autoAllowAll`：自动允许全部操作
- **高危授权二次确认防护**：
  - 用户勾选“自动允许全部操作”时，必须触发阻断式警告确认弹窗，明确说明允许 Agent 未经确认直接执行任意命令与修改文件的系统安全与数据丢失风险；用户点击取消则撤销勾选并保持原权限策略。

### 6.3 NAS 媒体库设计规范 (NasMediaView)
- **导航与系统接入**：
  - 新增 `AppSection.nas` 枚举与系统级导航映射（路由下标 9，图标 `Icons.perm_media`，本地化 `navNas`）；默认底部导航栏不默认包含该项，用户可在设置页自主勾选加入底栏或设置为主页。
- **页面架构与布局层级**：
  - **顶部摘要与操作栏**：展示当前绑定服务器、上次扫描时间（未扫描时明确提示）、扫描中状态动效；提供扫描配置按钮 (`Icons.tune`) 以及扫描/取消扫描按钮。
  - **独立搜索栏**：独占单行，带清除按钮与实时搜索防抖。
  - **媒体分类筛选**：提供“全部 / 图片 / 视频 / 音频”分段切换选择器 (`SegmentedButton`)。
- **状态流转与空状态规范**：
  - **未配置扫描目录**：展示醒目空状态插画与文案，并提供直接调起“配置扫描目录”弹窗的主操作按钮。
  - **未建立索引**：展示“媒体库暂无索引”提示，引导用户点击“开始扫描”。
  - **搜索无结果**：展示无匹配结果并提供“清除搜索”按钮。
  - **扫描进行中**：展示常驻细进度条 (`LinearProgressIndicator`)，操作按钮转为“取消扫描”。
- **扫描配置弹窗 (NasScanConfigDialog)**：
  - 直观呈现包含路径（扫描范围，带 `[扫描范围]` 标签）及其下挂的排除子路径（层级缩进，带 `[已排除]` 标签）。
  - 支持调用独立的 SFTP 远端目录树选择器 (`RemoteDirectoryPickerDialog`) 浏览远端目录添加路径，不破坏现有 SFTP 文件浏览状态。
- **媒体展示与性能降级**：
  - 图片采用响应式网格布局，缩略图通过 `FutureBuilder` 异步加载本地缓存与远端拉取；针对大文件（>20MB）或加载失败优雅降级为占位图标。
  - 视频与音频采用紧凑元信息列表展示文件尺寸与修改时间。
  - 列表/网格支持平滑无限滚动，滑到距离底部 200dp 时自动触发 `loadMore`。
  - 点击媒体项提示进入后台传输队列并在下载完成后自动调用系统打开。
