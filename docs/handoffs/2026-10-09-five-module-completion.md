## 已落地的业务改动

- 安全设置：真实指纹列表与撤销、按服务器清理本地密码/私钥/sudo 凭据、
  默认 Agent 校验及本地响应式摘要；未知主机没有确认回调时不自动信任。
- ACP：运行设置部分失败回滚，草稿保存成功后更新状态；取消历史加载时
  清理加载标记，避免断线后无法再次加载；增强日志凭据脱敏。
- 文件：同服务器无覆盖复制/移动、批量删除或普通文件下载、逐项结果、
  服务器独立书签及失败传输重试。保留原隐藏文件与符号链接改进。
- Docker：按 Compose 标签分组，针对确认过的现有容器 ID 执行启动/停止/
  重启，隔离服务器变更并返回逐项结果。
- 配置迁移：版本化白名单 JSON、排除托管凭据/指纹/历史/本地私钥路径，
  新 ID 追加及关联重映射、全局偏好显式选择、写入失败回滚。解析错误使用
  固定错误码，回滚失败后尝试重读持久化存储，避免乐观缓存伪装成功。

五项代码与界面均已落地；真实服务器、账号及原生平台交互仍需独立环境验收。

## 明确限制

同服务器复制/移动要求 GNU coreutils；进程突然中止可能留下复制临时目录。
配置导入回滚覆盖可报告的写入失败，不保证进程被杀时的多键原子性。自定义
Agent 或快捷命令文本可能自行嵌入敏感信息，导出必须由用户预览检查。
