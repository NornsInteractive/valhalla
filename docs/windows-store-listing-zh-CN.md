# 微软商店中文产品信息

产品名称：Valhalla-服务器运维管理工具

## 说明

Valhalla 是面向开发者、系统管理员和个人服务器用户的远程运维客户端。将 SSH 终端、服务器状态监控、文件传输与日常管理集中在一个 Windows 应用中，方便你连接和维护自己的服务器。

通过 SSH 连接远程主机，打开多个终端会话，查看 CPU、内存、磁盘和系统负载，管理进程、systemd 服务及 Docker 容器。内置 SFTP 文件管理器，可浏览远程目录、编辑文本文件，以及上传和下载文件；常用操作可保存为快捷命令。

Valhalla 还支持连接你配置的 AI Agent，查看流式响应与工具调用，并处理需要授权的操作。可在设置中启用实验性的 CLI 会话和 NAS 媒体库功能，连接远端工具及个人媒体服务。

应用提供 17 种界面语言，以及主题和强调色设置。无需注册 Valhalla 账号。连接配置、偏好和相关会话数据保存在本地；连接服务器、使用 AI 或访问媒体时，会与所选服务通信。应用内可离线阅读中文和英文隐私政策。

使用前请准备你有权访问的服务器及连接凭据。服务器管理主要面向支持 SSH 的 Linux 主机；systemd 和 Docker 功能需要远端安装相应组件。AI 功能需要自行配置兼容工具或服务，可能涉及第三方账号、订阅或用量费用。Valhalla 不提供服务器托管或内置模型服务。
