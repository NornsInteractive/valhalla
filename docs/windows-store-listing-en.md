## Description

Valhalla is a remote server management client for developers, system administrators, and personal server owners. It brings SSH terminals, server monitoring, file transfers, and everyday administration together in one Windows app, helping you connect to and maintain your own servers.

Connect to remote hosts over SSH, open multiple terminal sessions, and view CPU, memory, disk usage, and system load. Manage processes, systemd services, and Docker containers. The built-in SFTP file manager lets you browse remote directories, edit text files, and upload or download files. Save frequently used commands for quick access.

Valhalla also connects to AI Agents you configure, displays streaming responses and tool calls, and lets you handle operations that require authorization. Optional experimental CLI sessions and a NAS media library can be enabled in Settings to access remote tools and personal media services.

The app offers 17 interface languages, along with theme and accent color settings. No Valhalla account is required. Connection settings, preferences, and associated session data are stored locally. Connecting to servers, using AI, or accessing media involves communication with the services you select. Chinese and English privacy policies are available for offline reading within the app.

To use remote features, you need a server you are authorized to access and valid connection credentials. Server management primarily targets Linux hosts with SSH support. The systemd and Docker features require the corresponding components on the remote host. AI features require compatible tools or services that you configure and may involve third-party accounts, subscriptions, or usage fees. Valhalla does not provide server hosting or a built-in AI model service.
