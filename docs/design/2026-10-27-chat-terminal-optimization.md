# 智能会话与 SSH 终端优化

本轮六项全部实施，分三阶段可用版本交付。UI 沿用现有主题、导航及终端自定义网格；每阶段独立验证并新增版本，不覆盖旧版。实现回执见 [工作记录](../../agent-workflow/2026-10-27-conversation-terminal-optimization.md)。

## 阶段一：恢复反馈与阅读性能

连接、远端任务和本地历史同步分开表达；提示使用顶部覆盖层，内容、草稿与阅读位置保持。短暂成功提示约四秒消失，失败可关闭、复制诊断及针对原目标重试；关闭一次错误不隐藏后续独立的同类错误。

终端历史展示按来源隔离的最近检查时间，失败探测也更新时间，来源未查过时明确显示。现有 INVALID_RESPONSE 故障尚缺实服响应，仅补脱敏、转义、限长诊断，保持严格身份校验；不以新终端替代恢复。

普通段落和闭合代码围栏可独立渲染，复用 Markdown 组件对未变化块的缓存。引用式链接、列表、引用、表格、HTML 或缩进等复杂语法保留整体解析，优先保证内容语义。历史代码超过三十行默认预览十二行，支持展开、复制完整代码和独立阅读；统计逻辑行数不删改原文末尾换行。展开状态按会话/消息/块隔离，生成完成或其它回复开始时保持已有状态。工具输出沿用分页并保留展开状态与事件顺序。

## 阶段二：本地检索与定位

智能会话默认检索当前会话，可切换当前服务器；遵循现有 Agent/共享会话过滤。正文、代码和已经保存的完整工具输出纳入字面、不区分大小写检索。SQLite 读取在 Isolate 中执行，参数化查询，默认每页三十项、三百毫秒防抖，游标分页和选择版本隔离迟到结果。远端历史继续由用户主动导入。

搜索命中打开独立只读定位阅读器，加载目标前后各十五条，保留搜索词与结果位置。工具输出命中定位到实际保存内容附近，按需分页。阅读不会替换正在运行会话的连续消息窗口，不修改草稿或远端上下文。可通过原会话入口继续操作；远端文件链接不借用当前其它会话的执行环境。

终端检索只读本地回滚缓冲，提供计数、上一处/下一处、返回最新；手机菜单进入，桌面 Ctrl+Shift+F / macOS Cmd+F，不截获应发送远端的 Ctrl+F。按页签持有搜索状态，宽字符、软换行、滚动及缓冲更新后的定位需校验；关闭搜索不自动召回终端输入法。

## 阶段三：上下文与快捷操作

输入框周围保留模型/推理/权限入口，显示实际生效值；上下文标签可查看、预览和移除目录/附件/技能。命令搜索、最近使用与收藏按服务器、Agent 和执行环境隔离，只保存标识；当前目录已移除的条目可显示不可用并移除收藏。选择先填草稿，由用户发送，不为元数据菜单创建会话。

终端保留用户网格、方向键位置/颜色和高度。明确单次修饰与锁定状态，支持解除全部；按压/锁定/解除使用局部 120–180ms 反馈并尊重减少动画。触控区域尽量达到 44dp。普通键帮助不干扰修饰长按、方向连发及编辑拖动。后台、断线、页签变化或触摸取消时清理临时按压，常用命令复用现有仓库、预览/编辑后明确发送，多行仍确认。

## 验证与发布

覆盖背景切换/重连/迟到结果、长正文与代码、链接/表格语义、展开和复制完整性；本地万条消息/大工具输出检索、中文与 Unicode、跨 Agent/服务器隔离、分页与缓冲更新；草稿上下文隔离、失效能力、Gboard 组合键、取消触摸和减少动画。

使用模拟协议、隔离数据库和专用 tmux fixture，验证不写入真实 Agent 或生产终端。UI/ARB 由指定 AgY 完成，OpenCode 免费模型优先验证，不可用时使用已核验免费的 CodeBuddy；主代理不自行代跑应用测试。每阶段按现有发布脚本正式构建 Android 三架构 APK/AAB 与 Linux x64，推送 GitHub/Ygg 代理、核对哈希与 Range，再同步官网；不启动 Actions 或构建 Windows/Apple。实服和设备验收范围须在各发布回执中单独列明。

环形缓冲约束：替换逻辑列表后每行index必须与实际位置一致；移除前缀时旧行脱离、剩余行索引从零开始。搜索锚点验证依赖这两个不变量，不能以即时反复重查掩盖错误位置；已修正共享数据结构，发布前须通过满缓冲重排、清理与UI回收回归。
