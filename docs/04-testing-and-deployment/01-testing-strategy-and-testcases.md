# Valhalla - 测试策略与全功能验收用例矩阵

## 2026-09-20 CLI 长历史回归

- 模拟至少 25 条 Codex 历史：首次只请求最后一页，上滑逐页读取到最早消息；另以工具 item 占满首个原始页，验证客户端会继续分页直到取得足量可显示消息。断言没有 `thread/read(includeTurns: true)`，无重复、顺序正确。
- 点击历史会话期间切换会话 / Agent：迟到的消息页不得覆盖当前会话；生成完成后只刷新最新页。旧版不支持分页时显示版本能力提示。
- 移动端会话抽屉切换 Agent 后保持打开，选择具体会话后仍关闭。长历史的实际流畅度须在 Android profile 真机验证，自动化测试只证明请求有界与状态正确。

## 2026-09-19 增量门禁

- 原生 CLI：刷新 / 切换 / 新建草稿零创建，首次发送单次创建；服务器 / Agent / 执行身份隔离；真实协议审批载荷；分页 / 目录过滤；远端删除明确确认、忙时阻止、失败保留、无官方支持禁用；缺依赖与认证未知不自动安装 / 登录。
- 重启：Root / NOPASSWD / 仅本次密码、目标切换取消、双击不重复、发送断线未知、不自动重试、有效 boot_id 改变才能验证。
- 运维：Docker 单容器锁与其他容器并行、finally 清理和迟到结果；并行 SSH 退出码独立、最终输出 drain、缺退出状态不是成功；75ms 最新 PTY resize、取消 / 重连、dispose 后晚到通道关闭。
- 性能：同一物理 Android 设备 debug / profile 开关键盘 20 次，终端 / CLI / 聊天 / 文件 / 表单各测 UI 与 Raster 超预算帧；无设备时标记待验收，不能用 widget 测试代替帧率证明。
- 本轮不执行真实服务器重启 / 删除 / 安装，真实 CLI 版本与平台行为必须另做受控验收。[本轮记录](../handoffs/2026-09-19-cli-reboot-performance.md)。

## 1. 测试金字塔策略 (Testing Pyramid)

```text
         /  E2E 集成测试  \        <-- 真实 Linux 服务器联调 / 真实 ACP 交互 (10%)
        /------------------\
       /   Widget 组件测试   \      <-- 页面交互、输入验证、弹窗审批响应 (30%)
      /----------------------\
     /      单元测试 (Unit)    \    <-- 数据解析、JSON-RPC 编解码、加密存取 (60%)
    /--------------------------\
```

### 1.1 单元测试关注点
* **数据模型与解析**：`ContainerModel.fromJson()`, `SshHostKeyVerifier`, 快捷命令占位符插值。
* **ACP 协议编解码**：验证 JSON-RPC 请求生成、流式 Delta 拼接、`permission/request` 回调。
* **本地持久化**：内存 SQLite (Drift In-Memory) 表级增删改查。

### 1.2 集成与模拟测试 (Mock Architecture)
* 封装 `MockSSHClient` 与 `MockSSHSession`，无需真实连接远程主机即可模拟：
  * 网络超时、认证失败、Host Key 冲突；
  * 标准 ANSI 终端数据流；
  * Agent 抛出的各种异常状态码。

### 下载专项验收（2026-09-18）

- 自动化：并发同名路径不覆盖、路径清洗、下载写入 `.part`，仅成功后改名；未完成不能打开、完成调用系统打开接口。
- 设备：连续下载进入队列，无入队即成功提示；约300ms传输入口动画，减少动态模式不播放位移动画。
- Android 13+：允许及拒绝通知权限各测一次；允许时通知显示文件名和实际进度，拒绝不影响下载；完成通知及传输记录打开系统应用选择器。
- 安全：FileProvider 仅覆盖应用下载目录、URI 临时读授权；失败/取消文件不能作为完成文件打开。
- 桌面：Windows/Linux 各自构建及桌面会话实测系统应用选择器和通知；Linux 编译通过不能替代 Windows 验收。

## 2026-09-19 六项体验改进验收补充

- 容器终端：默认 Bash、缺失 Bash 回退 Sh、显式 Sh 不探测 Bash、两种 Shell 失败报错；服务器与容器名称偏好隔离。真机连接至少覆盖 Bash 与 BusyBox/Sh 容器。
- SFTP：根目录不显示 `.`/`..`，子目录仅显示 `..`；搜索、排序、返回上级不回归。
- CLI：新草稿选择工作目录后首次发送带该路径；历史筛选不影响草稿目录，已有会话保留原目录，切服清空未发送状态。
- 硬件卡片：CPU、内存、磁盘、发行版、内核部分缺失时显示未知；断线和切服不显示旧服务器数据。
- 展示层：服务器表单在窄屏和键盘弹出时可滚动且能保存；两个智能会话列表按钮与全局菜单图标可区分。
