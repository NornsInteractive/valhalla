## 2026-10-13 当前数据清理行为

本轮用户授权主代理直接修复、验证、构建和 ADB 保留数据覆盖安装，取代下方
历史未交付检查点。实际结果见[最新验收记录](../../agent-workflow/2026-10-13-picker-cleanup-verification.md)。
卸载默认保留目录与卷；可逐项勾选并确认风险和完整应用名称。系统子目录、
共享路径可显式授权，整个OS根、运行时／管理树及链接／挂载点仍禁清理。命名卷
和匿名卷用 Docker API 删除，仍被其他容器引用时会失败保留，不停止其他应用。
检查和执行分别复验身份／配置／引用；失败只报告真实部分结果，不承诺数据回滚。
重试只重新检查之前未成功清理的授权目标，并再次由用户确认，不自动执行。

选择目录在手机上也为弹窗且不显示文件；选文件可过滤类型和扩展名，保留
路径、搜索、隐藏、排序和视图，不提供传输管理按钮。关闭不恢复旧输入法。

## 启用与目标

设置 → 实验性功能 → 应用中心。默认关闭；开启后可从菜单进入，也可自行
设置导航位置、默认启动页或仪表盘快捷入口。关闭只隐藏入口，不删除已部署
应用或停止远端任务。安装发生在当前选中的 SSH 服务器，不在手机/电脑本机。

应用中心包含商店、已安装、任务三个页签。官方源为 CasaOS/ZimaOS v2；可
添加可信 HTTPS 商店地址。源提供容器镜像与模板，添加第三方源前需自行确认
可信度；content_hash 只是变更标记，不是安全签名。

## 安装与管理

1. 连接 Linux 服务器并选择应用，等待环境检测。
2. 缺少 Docker/Compose 时明确确认安装；自动安装仅支持已声明 Debian/Ubuntu
   版本和 amd64/arm64，不删除冲突软件，也不替换服务器已有 Docker。
3. 设置名称、独立数据目录、端口、挂载、变量及环境参数，明确选择访问范围，
   核对部署预览后确认。每个端口可以继承应用默认或单独覆盖；旧配置保持原范围。
4. 在任务页观察阶段和日志。断线或退出后远端任务继续；重连核对原任务 ID。
5. 安装成功后默认经 SSH 打开 HTTP Web 页面；HTTPS 或外部访问可显式使用直连。

已安装页支持启动、停止、重启、日志、修改配置、手动更新、恢复上一次配置、
卸载。配置编辑读取安装时模板，不依赖商店仍存在；编辑或启动固定已有镜像，
不会顺带更新。只有明确更新会读取新模板并拉取镜像。卸载保留数据与卷。

## 操作体验与恢复

- 手机详情与任务详情全屏展示，桌面使用有界弹窗；搜索与筛选跨页签保留。
- 源刷新失败保留已有目录并提示出错来源；换同 ID 源的地址不会继续混用旧数据。
  官方翻译片段与完整目录按应用 ID 合并，切换中文不会把翻译索引当成不支持的源。
- 提交后可转到任务页，成功并核对实际实例后可转到已安装页或打开服务。
  关闭进度页面不取消远端任务；未知结果只能重新核对，不盲目重复安装。
- 任务详情可选中／复制已限长日志。只有可安全取消的阶段允许取消，执行配置
  或启动阶段不会提供错误的取消承诺。离线、其他任务进行中时禁用相应操作。
- 停止／重启／卸载需确认；切换服务器后，旧详情和未提交向导必须重新打开。
- 回到前台自动核对服务器实际状态，同一次核对合并请求，不重复启动任务。

## 边界与风险

- `127.0.0.1` 仅服务器本机/SSH隧道访问；`0.0.0.0` 监听所有IPv4网卡，
  不代表仅局域网。外部能否访问还取决于服务器地址、安全组、防火墙及路由。
  App不自动开放防火墙。Nginx代理管理器可将管理81端口留在回环、代理80/443
  独立设为外部。只读诊断报告实际Docker绑定和本机HTTP响应，不承诺公网连通。
- 任务日志只保留有界滚动尾部，不是永久审计日志；当前命令和正文不写入本地
  偏好。无新输出不代表失败；临时同步失败保留最后阶段，不能自动重发安装。
- 官方CasaOS镜像源仅在网络/DNS/超时/5xx失败时尝试同仓库GitHub Raw地址。
  TLS、内容错误、超限与自定义源不触发此回退；刷新失败保留缓存并显示来源错误。

- 不支持原生 fnOS 包、旧 ZIP 源、任意宿主安装脚本、特权/设备应用或全局外部卷。
- 恢复包含 Compose、镜像及配置；不回滚数据库或挂载文件，重大更新前需自行备份。
- 已安装数据根目录不能通过编辑迁移；外部挂载须预先存在且有权限。
- 若有人在 App 外删除了应用容器，无法确定原镜像时会拒绝需要精确快照的操作，
  不假装恢复成功、不删数据。未知任务结果要求检查，不自动重复执行。
- 断线期间展示缓存不是在线证明，远端变更必须等待连接恢复。
