# Valhalla v1.0.4 发布记录

本次由用户确认仅在当前 Linux 环境本地构建 Android 与 Linux，不启动
GitHub Actions，不构建 Windows／macOS／iOS；不复用旧包改名冒充新版。
版本为 `1.0.4+5`，团队 **Norns Interactive**。旧 v1.0.3 与 Windows 下载保留。

## 发布内容与边界

本版纳入当前源码中的 SSH 终端显式键盘按钮、阅读位置保持、快捷栏与粘贴保护，
远程文件隐藏项弱化和持久化列表／卡片切换，以及已实现的后台恢复、传输与
GitHub 更新基础能力。更大范围的编辑器、系统服务和 NAS 消费者交互仍有待
完成；不宣称全部九项需求交付。真实远端、手机输入法与 Linux 桌面体验不
由自动化测试或编译代替。本次发布不执行 ADB 安装或清除用户数据。

Android 使用既有包名 `com.antigravity.valhalla.valhalla` 和固定发布证书
SHA256 `73dc6d178bbd7aba1ef85dd18b266ad491ae000c08915b9ee62cfc8383a92c7d`。
不更换私钥、别名或签名；证书主体与团队展示名称的区别见
[签名说明](05-android-release-signing.md)。发布包不能覆盖此前调试签名安装，
不得以卸载／清数据方式绕过签名不兼容。

## 计划产物

- `valhalla-v1.0.4-android-arm64-v8a-signed-5.apk`：多数现代 Android 手机。
- `valhalla-v1.0.4-android-armeabi-v7a-signed-5.apk`：32 位 ARM。
- `valhalla-v1.0.4-android-x86_64-signed-5.apk`：对应设备／模拟器。
- `valhalla-v1.0.4-android-signed.aab`：应用商店上传格式，不能直接安装。
- `valhalla-v1.0.4-linux-x64.tar.gz`：完整应用、库、数据与许可说明。
- Android／Linux `BUILD-INFO.txt`、SHA256 汇总及单独校验文件。
- `update.json` 与校验文件：由既有工具读取真实 APK 身份及最终产物生成，
  用于应用更新检测，来源提交、大小和哈希必须与本次发布一致。
