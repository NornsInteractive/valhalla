# Valhalla v1.0.3 本地构建与发布

版本 `1.0.3+4`，团队 **Norns Interactive**。用户最初要求 Windows 云端构建、
其他平台本地构建，随后明确补充“除了 mac、windows 都构建上去”：本次只在
当前 Linux 环境构建 Android 与 Linux，不构建 Windows/macOS，不启动 Actions。
iOS 同样依赖 Mac/Xcode，本机无法构建，不上传旧版重命名的 iOS 包；项目没有
Web 目标，不在本轮新增 Web 支持。

本次发布纳入当前已完成的安全设置、ACP 回滚与历史加载恢复、远程文件批量
操作与书签、Docker Compose 项目管理、无托管凭据配置迁移，以及原有紧凑
导航／隐藏文件／目录链接改动。保护备份 stash 保留，不丢弃工作区源改动。
实现本地验收为 2165 项通过／18 项独立环境检查跳过／零失败，静态检查无问题；
真机、真实服务器、账号授权和各平台运行体验不由编译或模拟测试保证。

## 发布约束

- 使用精确发布提交的隔离源码树构建；提交包含 `[skip ci]`，不手动触发工作流。
- Android 应用 ID 不变，沿用固定正式签名，公开证书 SHA256：
  `73dc6d178bbd7aba1ef85dd18b266ad491ae000c08915b9ee62cfc8383a92c7d`。
  私钥、密码、登录凭据不进 Git、不进构建说明、不上传 Release。
- OpenCode 使用任务独立配置，主／辅助均为用户已授权的免费回退
  `opencode/step-5-preview-free`；负责检查、构建与产物验证，不修改全局工具配置。
- Android 产物为正式签名 ABI APK 与 AAB；AAB 不直接安装。Linux 产物为完整
  x64 bundle 的 tar.gz，不只上传可执行文件；目标机需 GTK 3、libsecret、libmpv。
- 所有包记录团队、版本、源码提交及 UTC 构建时间，提供 SHA256 校验。
- 先创建新的 `v1.0.3` 草稿，上传明确白名单并核对服务端名称、大小、digest，
  核验完成才正式发布。旧版 Release、标签、资产保留，不使用覆盖上传。
- 本轮不 ADB 安装、卸载应用、清除用户数据或执行真实远端命令；不修改计费、
  支出额度、仓库可见性、正式签名和旧包。
